# 2048
## Project Description:
This is a clone of the popular 2048 game. It is implemented using JavaScript, where the player moves tiles around the grid to combine them and reach the 2048 tile. The game includes features like keeping track of the score, displaying the highest score (with localStorage), and showing win/loss messages when the game ends.

## Technologies Used:
- HTML: Used predefined HTML
- CSS: (with SCSS): Used predefined SCSS
- JavaScript: Core game logic, movement mechanics, score handling, win/lose conditions
- localStorage: Saving the highest score
- DOM manipulation: For updating the board and score dynamically

## Additional Instructions for Running the Project:
1. Install dependencies by running the following command in the terminal: `npm install`
2. To open the project in a browser, use the following command in the terminal: `npm start`
   
Alternatively, you can open the HTML file directly in a browser.
